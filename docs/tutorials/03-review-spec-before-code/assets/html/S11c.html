实录 · 示例项目
D1缺 errcode 会被判成功（design-voice、hr-tg、对抗 B）。
普通 int 解码时，{}、{"errcode":null} 都留零值，
被当成推送成功；
之后冷却生效，后续提醒也被抑制。
白话：返回里没有 errcode（或是 null），Go 解出来是 0，当成发送成功；之后进了冷却，后面的提醒也发不出去。
处置design 第 8 条与 NTF-05：
errcode 解码为 *int，
必须非 nil 且为 0。
白话：用指针接 errcode；字段缺失或者为 null 时是 nil，算失败；只有明确返回 0 才算成功。
