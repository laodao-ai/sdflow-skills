怎样使用

视频包含作者讲解；博客便于阅读和查链接。HTML 页面用于逐页查看动画、图解和演示画面，不含完整口播和成片字幕。

  • 点目录可跳到任意画面。
  • 空格暂停或继续，左右方向键切换画面。
  • 按 T 显示或隐藏目录。

内容与版本

这些页面保留本期制作时的画面。工具命令与界面可能随版本变化，使用时请对照 SDFlow 当前说明。

页面中的终端内容是录制回放或讲解示意，不会在你的电脑上执行命令。不同画面的证据范围以页面标注为准。
