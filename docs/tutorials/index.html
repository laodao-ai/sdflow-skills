使用说明

下载本目录后，用浏览器打开本页。若浏览器限制本地嵌入页面，可在本目录运行 python3 -m http.server 8000，再访问 http://localhost:8000。

HTML 连播不含完整口播。请通过各期的 B站或 YouTube 链接观看完整视频。历史画面保留录制时的工具版本，不代表最新命令。

本目录按期保存教学发布快照。字体共用一份，各期画面与播放器保留原有行为。
