01 — 贯穿全流程的铁律

五条全局不变量

这些不是某一步的细节，而是整条流水线共享的铁律——读懂它们，才读得懂每步为什么这么设计。

①唯一人类门

只在阶段二设计门停。阶段二错 → 白做，值一个门；阶段三已实现、残差可追踪，不值门。

grill 是对话岛不折叠；阶段三禁 AskUserQuestion，走三级决策协议。

②连续跑 · 无 /clear

评审本就 fan-out 到 fresh-context 子代理，独立性由此而来，不由 /clear 给。

子代理调度运行中仍禁 /clear，必须跑完再进下一步。

③每步 checkpoint

「逻辑步骤完成」是语义不是事件，不用 hook；碎 commit = 细粒度回退点。

grill 多轮中途不提交、只收敛后一次；不 squash。

④反静默压制

裁掉的 reviewer finding 只能降级/批注、不得静默丢，连理由落报告「已裁掉」区。

焊死热主 session 带生成历史裁决的合成层偏置。

⑤防假 ✅

去人类门后 verify 是唯一终门。每条 ✅ 必附机验锚点（测试名 / commit / 文件:行）。

verify 用强模型 + 「Do Not Trust the Report」冷启，禁降档。

↳ 一条主线

把不变量焊进确定性载体（脚本/文件/被门读的 git 产物），把判断留给强模型 + 冷子代理。见 §04。

02 — 阶段三最底层

ship_gate 判定机

编排器 /sdflow-ship 每步前后必调 gate，照判定走、禁凭 prose 记忆步序。 gate 从盘面（产物 + 锚 + checkpoint 标签）推导「下一步是谁」，每个执行完的步都回到 gate 再问——这就是「盘面即状态」。

resume · 人机同权

ship 零跨步内存状态——任何时刻中断，重调 /sdflow-ship {change} 即从盘面推导缺口续跑；期间人工手跑某步产出的报告同样被 gate 认（gate 不辨产者），手改锚行 = 显式越权通道（git 留痕可审计）。

04 — 理解全部详解的总纲

注入的强制性：建议式 vs 强制

元规律

本 workflow 往 skill 注入的规则/prompt 绝大多数是「建议式」；真正的「强制」不靠控制 skill 内部， 而靠在下游放一道读 git/文件的确定性门——注入本应产出的锚/产物产不出，就 REFUSE / 循环重跑。注入处建议式，下游门处强制。

prompt 注入
建议式，可被执行它的模型忽略（无特权分级）
→
skill 执行
模型自觉产出锚 / 产物 / commit
→
下游确定性门
读到 → 放行（强制生效）；读不到 → REFUSE / 循环

八个注入项的定性汇总——只有背后有确定性载体（脚本/文件/被门读的 git 产物）的才转「强制」：

findings 落盘 + 进合并池autoplan / review编排层主 session 落盘 + grep 锚行自检

sdflow-* 自己带机械门——锚行存在性自检（grep 三类 v1 锚缺失即报错阻塞，抓漏镜）、ship-gate 锚、 archive CLI validate、buglist FIXED 门禁、git --ff-only——这些是强制；而判断层 （对抗裁决、反静默压制、置信分流、verify 防假✅、model 档位）是建议式，靠强档主 session + 铁律 + 下游门兜底。 唯一刻意不机械化的是 grill（人类对话岛），严谨性靠人类在场 + 下游设计门审计。

05 — 从 gstack / superpowers / grill 提炼

自建 skill 最佳实践

可迁移做法逐条对照「我们已内化 ✓ / 值得补强 ⚠」。大部分我们已在用，可作为验证过的正确做法固化。

状态
状态外化进文件/git，对抗 compaction；停即停、重调即续✓
交接
大产物给文件路径，dispatch 只描述一个任务、不贴历史⚠ 部分
独立
独立性靠 fresh 子代理，不靠 /clear✓
防假绿
Do-Not-Trust + 每 finding 引原码 + 置信过滤（低置信可审计不静默丢）✓
评审
禁 pre-judge findings；escalate-not-drop✓
去门
明码决策原则 + 审计留痕；人类门分级 + 批处理⚠ 缺原则集
降级
每条降级显式打日志/写锚，绝不静默✓
强制
下游放确定性门读锚/产物，把「建议」变「强制」✓
模型
按角色选档、必须显式指定；turn count beats token price✓
脚本
机械活交脚本、模型只做判断；载重不变量用 MUST/STOP✓
注入边界
发外部模型的 context 围栏掉 skill 定义文件⚠ 缺前缀
对话类
刻意不机械化保开放性；稀疏产物设门槛；姿态=触发即反应✓

三条可执行补强

1

编本地「决策原则清单」

仿 autoplan 6 原则 + 三分类，供 T10「有客观判据自动选」引用。现只有协议、无明码原则集。

2

大产物走文件交接

多镜 fan-out 的大 diff/报告仿 SDD review-package 走文件，不返回进主 session 压上下文。

3

发 codex 加 injection 前缀

outside-voice 的 context 加「不读 skill 定义目录」前缀，补齐边界（autoplan 已有、我们缺）。
