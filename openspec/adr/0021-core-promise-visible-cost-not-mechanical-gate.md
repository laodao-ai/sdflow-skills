# 0021 · 核心承诺无机械兜底：**代价可见 > 机械拦截**

> 状态：**Proposed**（2026-07-14，grill `add-sdflow-devenv` 收敛时立）——待该 change ship + 首个真实项目试点后升 Accepted。
> 关联：`docs/sad/07-devenv-skill-design.md` §0.1（身份定调）· §0.0（四道闸门）· 附录 **A23**（总病根）· CONTEXT「副驾 / 留白·待定 / 层状态」· `adr/0018`（机械校验器输出诚实）· `adr/0008`（gate 纵深防御 vs 信任纪律）。

## Context

`sdflow-devenv` 的核心承诺是「**不管什么项目，都给一份三层测试策略——一层都不许留白**」。

早期设计把「不许留白」交给机械层：`devenv_lint.py` **fail-closed 拦截**空槽。这条路走到底的结果，被附录 A23 记录：**18 个 Task 里 10 个是机械防漏基础设施（1646 行代码 + 测试），而核心承诺的智力载体（`references/` + `SKILL.md`）零字。** skill 本身一行没写，给它记账的账本已经写了 1646 行。

操作者的定调（2026-07-14）推翻了这条路：

> **「这个 skill 是辅助我来搭建开发测试环境的，同时提醒我要考虑哪些事情别忘了。」**

**skill 是副驾，不是审计官。** 副驾提醒你「油快没了」；审计官证明你没在油表上作弊。

而追到底，机械兜底**在原理上也不成立**：
- 「该问的没问」——按 §0.0 是**漏**，机械层 MUST 保证；
- 但**「问没问」与「跑没跑」同构**——agent session 里模型是唯一执行者，**机械上不可区分** ⇒ 按 §0.0 又是**伪**，机械层 MUST NOT 管。

**两条推论撞车。没有任何机械能保证 skill 真的问了。**

## Decision

**核心承诺「一层都不许留白」，由「问」兑现，不由「拦」兑现。机械层不为它兜底。**

1. **「留白」重定义** = **该问的没问出口**，**不是**「格子里没字符串」。
2. **`⚠️ 待定` 是合法产物**——人被问到、当场答不上来，如实落它。schema 放行，**即便三层十八格全是待定**。
3. **真正的防线是两条，都不是拦截**：
   - **A 层（脑）**：`references/testing-framework.md` 的**提问清单** + `SKILL.md` 的**提问纪律**。清单保证「每次都问同样的十八个问题」——**枚举完备性不能靠模型临场回忆**。
   - **代价可见**：`testing-strategy.md` **顶部渲染横幅**（`⚠️ 本框架 12/18 格待定，尚不构成一份可用的测试策略`）+ 收尾报告**逐条列出**所有待定项。
4. **机械层只拦「人看不见的」**：`status` 拼成 `verifed` · 路径穿越 · JSON 结构坏了。**「人一眼看得见的」（六槽留白、`不适用` 没写后果）只报不拦。**
5. **推论（结构性保证 > 拦截）**：能让坏事**没法发生**的，用结构（层状态从泳道**投影**算出 ⇒ 无法伪造；命令表**从 JSON 渲染** ⇒ 双写不可能发生）；**不能的，就诚实呈现，别造一个拦不住的闸机。**

## 为何这样（判据）

- **闸门 0（形态问）**：「三层六槽有没有留白」**有确定性信号、有承载字段、代价也不高**——三道闸门全过，然后造出一个 lint 去拦**一个人一眼能看见的空格子**。**正解是在对话里问他一句。** ⇒ 前三道闸门全过，仍然可以是错的（`07` §0.0）。
- **拦截会奖励空话、惩罚诚实**（round-3 对抗镜实证）：拦一个空的 `strength`，**并不会让模型写出好的 `strength`，只会让它写出「一句话」**。而一个 fail-closed 的 lint，会让「不适用 + 后果」这种诚实答案，和「编一段废话」这种敷衍答案，**得到同样的绿灯**。
- **§0.0 自己写下了解药，只是没用在自己身上**：**「让人看得见，而不是让脚本抓贼。」** 它杀掉了「防伪」，却把「防漏」原地留在了机械层——于是 lint 依然是评估器，只是评估对象从「真不真」换成了「全不全」（A23）。

## 代价（如实记，这是真的）

**核心承诺没有任何机械兜底。** 一个偷懒的模型（或一次上下文耗尽的 session）可以产出十八个待定，**技术上完全合规**，而用户拿到的是一份废纸。

**接受它。** 因为：① 那份废纸**一眼就能看出是废纸**（顶部横幅 + 收尾报告）；② 任何试图堵住它的机械，都必须回答「怎么证明 skill 真的问了」——**而那个信号不存在**，硬造出来的就是假绿，**而假绿比诚实的语义层更危险**（§0.0 推论 1）。

## 被否方案

- **阈值硬门**（待定 > 5/18 ⇒ 拒绝写出 `testing-strategy.md`）：阈值**无依据**（为什么是 5 不是 6），且**副驾开始拦人**——它会把「我这个项目确实还没想好 e2e」这种合法状态，变成一次失败的运行。
- **区分「已问·暂缓」与「未问」**（前者合法、后者 fail-closed）：需要一个「问过了」的信号，而**它不存在**——除非接受「模型自己写 `asked: true`」这种自证，**那就是假绿**（同 A18：agent session 里模型是唯一执行者）。
- **`devenv_lint.py` fail-closed 拦空槽**（原设计）：见上「为何这样」全部三条。
