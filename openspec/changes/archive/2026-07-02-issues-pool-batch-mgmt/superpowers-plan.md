# issues-pool-batch-mgmt（Phase B）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 buglist/todolist 债务池升级为 `issues/{buglist,todolist}/` 三维度结构 + 新增共享 `issues.py`（reindex/batch/INDEX/batches.md），并把 sweep 接入 opsx-done。

**Architecture:** 两个 per-type 脚本（`buglist.py`/`todolist.py`）保持只管各自 add/scan/set-status/triage + 新增「批次」列 + dual-read；新增一个共享层脚本 `issues.py` 独占跨 bug+todo 的 reindex/batch，owns `issues/INDEX.md` + `issues/batches.md`。真相源 = `openspec/changes/issues-pool-batch-mgmt/design.md`。

**Tech Stack:** Python 3（stdlib：argparse/os/re/json/glob/datetime/tempfile）；pytest；无第三方依赖（延续现有 recorder 风格）。

## Global Constraints

以下每条来自 design.md，每个 task 隐含遵守：

- **三维度分家**：源change（provenance，**不可变**）/ 批次（triage，可变）/ status（生命周期，**回归干净、不塞批次**）。现有「关联Change」列即「源」。
- **「批次」列追加在表末尾**（`关联Change`/源 之后），**不插「状态」前**——否则错位现有 `cells[4]`=状态、`cells[6]`=关联Change 的位置解析（D2）。
- **防御式位置解析**：沿用现有 `len(cells) >= N` 模式；旧无「批次」列文件读为空批次（I8 兼容）。
- **终态集**：bug=`{FIXED,WONTFIX}`、todo=`{DONE,WONTDO}`；批次完成判据 = 成员**数 ≥ 1 且全部进终态集**（0 成员保持 `PLANNED`，防 vacuous 假 DONE，D1）；`WONT*` 算合法闭合。
- **reindex**：拿 item 池当 ground truth 同步批次状态；**不做逾期主动催办**（I12 被动）；接入 sweep 步末（D3）；`issues/INDEX.md` 首行加 `<!-- GENERATED by issues.py reindex — DO NOT EDIT -->`（D3）。
- **命令归属（B-Q2）**：`issues.py` 独占跨类型 `reindex`/`batch`；per-type 脚本只管 add/scan/set-status/triage。
- **原子写（D6）**：所有文件写用 `tempfile` + `os.replace`（现有 recorder 是非原子 `open(w)`，本 change 收紧到原子写 helper）。
- **幂等（D7）**：reindex 连跑两次结果相同；`triage` 对已 `PROPOSED` 的 item **no-op**（不非法跳转）。
- **并发（D8）**：假定单机单进程串行调用、**不加锁**；在 issues.py docstring 显式声明该假设。
- **跨池 ID 前缀互斥（D9）**：B(bug)/T(todo) 前缀互斥为显式规范；`issues.py` reindex/join **跨池 ID 冲突检测**，撞号报错不静默。
- **Q1 加固（dual-read）**：`next_id`/`scan`/`list_files` 过渡期**新旧路径都扫**（新 `issues/buglist/` + 旧 `buglists/`）再取 max，避免撞号 + 旧债不隐形；跨路径同 ID 报错。
- **Q2 保守（批次命名）**：sweep 永远新建 1 批次、`key = 本change`、禁跨 change 合并；`batch` 加 `rename`；reindex 对 orphan 批次 tag（item 有 tag 但 batches.md 无此 key）**显式报警、不静默生成 ghost**。
- **Q3 精确 patch（batches.md grammar）**：字段级 grammar——**生成行**（`状态:`/`成员:`）由 reindex 维护，**人写行**（`优先级:`/`计划:`）reindex 绝不覆写；「标不一致纠正」= reindex **只追加 `⚠️` 警告标注行、绝不越权改人写状态值**（防震荡）。
- **失败模式（D5，design §8.1）**：dated 文件解析失败 → 跳过+报警不崩不静默；orphan 批次引用 → 报警；半写 → 原子写规避。
- **标准归属（I13）**：issues 结构标准写进 `buglist-recorder`/`todolist-recorder` 各自 SKILL.md 的「约定速查」段（单一真相源，不另起 rules 文件）。
- **测试**：`buglist-recorder/tests`、`todolist-recorder/tests` 现有 37 项保持绿；新增 `issues-recorder/tests`（或就近）覆盖 issues.py。
- **提交**：逐任务 `hack/checkpoint-commit.sh <task> "<desc>"`（过场提交）。

- [ ] Step 3: 实现 helper：

```python
import tempfile
def atomic_write(path, text):
    d = os.path.dirname(path) or "."
    os.makedirs(d, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=d, suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            f.write(text)
        os.replace(tmp, path)
    finally:
        if os.path.exists(tmp):
            os.remove(tmp)
```

把三处 `with open(path,"w") ... writelines(lines)` 改为 `atomic_write(path, "".join(lines))`。

def list_files(root):
