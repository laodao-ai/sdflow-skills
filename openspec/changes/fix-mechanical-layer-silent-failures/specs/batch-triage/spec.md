## ADDED Requirements

### Requirement: 严格性是默认值，逃生口必须在产物里留痕

取数产生非空阻断集时，命令 **MUST** 默认非零退出，**MUST NOT** 依赖调用方显式传入严格开关才生效。

**MAY** 提供显式逃生口放行，但该逃生口 **MUST** 同时满足三条：

1. **产物带疤**：放行后生成的 `INDEX.md` **MUST** 在其头部 banner 增记一行，说明本次重建有 N 条阻断级诊断被显式放行、索引可能不完整——**妥协随产物进版本库**，而非只在一次终端输出里闪过；
2. **禁止环境化**：**MUST** 仅接受显式命令行参数，**MUST NOT** 支持经 config 文件或环境变量开启（逃生口的真正死法是被写进配置后全仓永久生效）；
3. **禁止自动传递**：`/sdflow-done` 的 sweep 子步 **MUST NOT** 自动传入该逃生口。

> 依据（`adr/0018` 铁律 (d) 的推论）：预置一个默认关闭的严格开关**不构成防护**。实证：`reindex --strict` 已存在且零消费者，它的存在恰恰让默认值维持在错的一侧。

#### Scenario: 缺省即严格

- **WHEN** 取数产生非空阻断集，调用方未传任何开关
- **THEN** 命令非零退出

#### Scenario: 放行留痕（限写 INDEX 的命令）

- **WHEN** 调用方显式传入逃生口并完成 `INDEX.md` 重建
- **THEN** 命令以 0 退出，且生成的 `INDEX.md` 头部 banner 含被放行的阻断项计数与「索引可能不完整」的声明

> 适用面 `[gstack-amendment]`：banner 是 `INDEX.md` 的生成物，**只有写 INDEX 的命令**（`reindex`，及经它的 `sweep`/`batch rename`）具备该载体。不读两池的命令本就不产生阻断，无此场景。本 Scenario **MUST NOT** 被解读为「所有命令放行都留痕」。

#### Scenario: 逃生口不可环境化

- **WHEN** 试图经 config 文件或环境变量开启放行
- **THEN** 该设置不生效，命令仍按严格处置

### Requirement: sweep 用退出码区分「重跑可收敛」与「重跑无用」

`sweep` **SHALL** 以不同退出码区分两类失败，使调用方能机械判定要不要重试：

- **重跑可收敛**（triage / batch add 等子步半途失败，已 tag 项在重跑时被天然排除）→ 退出码 `1`；
- **重跑可收敛（瞬时）**（并发锁冲突）→ 退出码 `2`——**该码为既有占用，本需求不改其语义**；
- **重跑不收敛**（阻断集非空——盘面失配不会因重跑而消失）→ 退出码 `4`。

`[spec-review-amendment]` 初版把「重跑不收敛」赋给 `2`，**与既有占用冲突**：`main()` 的 `except ValueError → SystemExit(2)` 覆盖 `RecorderLockError(ValueError)`，而锁冲突是**瞬时可重试**场景，会被误判成「需人工介入」而硬停。∴ 阻断类改用空闲码；**落地前 MUST 先枚举全部退出码路径确认无占用**，MUST NOT 凭「看起来没被用」赋义。

退出码 `4` 的 stderr **MUST** 明说「重跑无用」，列全阻断明细，并给出两条出路（修盘面 / 显式逃生口）。

调用方（`/sdflow-done` §2.1）**MUST NOT** 对退出码 `4` 进入重试循环，**MUST** 停下上抛人工；对 `1` / `2` 按既有可重试语义处理。

sweep **MUST** 显式透传子进程的阻断码，**MUST NOT** 经既有 `_die`（恒 exit 1）路径把它压平。

sweep 的终步 `reindex` **MUST NOT** 以「本轮是否有新 tag」为触发判据——阻断后重跑时已 tag 项被过滤、`tagged` 为空会命中早退分支，导致**已写入的批次条目永远同步不进索引却 exit 0**。触发判据 **MUST** 改为「该 change 在批次注册表中存在条目」。

> 依据：既有契约承诺的「半途失败重跑收敛」描述的是**写操作幂等性**，本就未覆盖「输入数据有问题」。用退出码分开二者是**补全**该契约，不是推翻它。

#### Scenario: 阻断类失败不被重试

- **WHEN** `sweep` 因阻断集非空以退出码 `4` 结束
- **THEN** 调用方停止并上抛人工，**不**自动重跑；stderr 含「重跑无用」字样与两条出路

#### Scenario: 半途失败仍可重跑收敛

- **WHEN** `sweep` 因某项 triage 子步失败以退出码 `1` 结束
- **THEN** 既有语义不变——直接重跑同一条命令可收敛到完成

#### Scenario: 全自动链上硬停而非跳过

- **WHEN** `/sdflow-done` 的 sweep 子步收到退出码 `4`（`/sdflow-ship` 经 done 链序间接受影响，其自身不直接调 sweep）
- **THEN** 链路硬停等待人工，**MUST NOT** 跳过 sweep 继续推进（跳过等于丢失 defer 分诊——正是本次事故本身）

#### Scenario: 阻断后重跑不再漏掉索引同步

- **WHEN** 首轮 sweep 已完成 triage 与批次登记、终步因阻断退出；人修正盘面后重跑同一条命令，此时全部相关项已带批次标记、本轮新增 tag 数为 0
- **THEN** sweep **仍执行**终步 reindex，批次条目被同步进索引；**MUST NOT** 因「本轮无新 tag」而早退并以 0 退出
