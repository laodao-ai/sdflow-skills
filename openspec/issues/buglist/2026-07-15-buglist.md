## B7: outside_voice_guard.py:149 raw.isdigit() 对 Unicode 数字字符（如上标²/圈码①等 Nd/No 类）返回 True，但 int(raw) 对这类字符抛 ValueError——裸 Traceback 逃逸，而非契约式 stderr FAIL；pre-existing（Task 4 之前就有，非 add-codex-host-support 本次引入）

| 属性 | 值 |
|------|------|
| 模块 | `sdflow-init/assets/workflow/tools/outside_voice_guard.py` |
| 优先级 | P3 |
| 状态 | OPEN |

**现象**：findings="²" 之类含 Unicode 数字（非 ASCII 0-9）的锚字段值经过 raw.isdigit() 判真后被喂进 int(raw)，触发 ValueError 裸抛出，而非走脚本既有的 fail-closed FAIL 契约路径

**根因**：`str.isdigit()` 对 Unicode Nd/No 类字符（²、①等）返回 True，但 `int()` 只接受 ASCII 0-9，两者语义不对称。

**修复方案**：
- `raw.isdigit()` 前加 `raw.isascii()` 门（ASCII 外的 digit 一律视为 None，走 best-effort 跳过）

**影响范围**：outside_voice_guard.py 的 findings 解析；实际触发概率极低（findings 值由 LLM 产出，正常情况下是纯 ASCII 数字）
> 2026-08-03 状态：OPEN → FIXED（isascii() 前置门修复（assets + openspec/workflow 两份同步），42 测试绿）
