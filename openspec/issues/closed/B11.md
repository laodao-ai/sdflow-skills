## B11: sweep 对 canonical/overlay 模式的条目视而不见 → tagged 0 项、批次不建，done 收尾静默丢失 defer 分诊
> sweep 对 canonical/overlay 模式的条目视而不见 → tagged 0 项、批次不建，done 收尾静默丢失 defer 分诊

**关联文档**：`openspec/changes/async-outside-voice/design.md`

**现象**：跑 `issues.py --root . sweep --change async-outside-voice`：stderr 连报 `块有 B10 但缺总览表行` / `块有 T153..T163 但缺总览表行`，末行 `tagged 0 项，无匹配项，跳过 batch add/reindex`，exit=0。而实际盘面有本 change 的 11 条 todo + 3 条 bug，frontmatter 里均为 `"change":"async-outside-voice","batch":null`（即「非终态 ∧ 批次空」，正是 --open-ungrouped 口径应命中的）。

**根因**：旧版三脚本物理拷贝 + sibling-spawn 路径依赖——运行 checkout 的旧 buglist.py/todolist.py 不认识开发 checkout 引入的 canonical/overlay frontmatter 格式，只解析 legacy 总览表行，frontmatter-only 条目全部漏扫。

**修复方案**：
- `dedupe-issues-scripts-shared-layer` change 将三脚本合并为 `sdflow_issues_core` 单一 package，消除 sibling-spawn 路径依赖和三份物理拷贝的版本偏斜问题
- `effective_items` 正确合并 frontmatter items（含 canonical/overlay 模式）+ legacy items

**影响范围**：sweep / scan / reindex / triage / batch 全读取路径；根因已被结构性消除
