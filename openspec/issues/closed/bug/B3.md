## B3: 归档后 gate 无 SHIPPED 终态识别——change 目录移入 archive/ 后误报「未过设计门 REFUSE_START」而非 SHIPPED

| 属性 | 值 |
|------|------|
| 模块 | `sdflow-ship/scripts/ship_gate.py` |
| 优先级 | P3 |
| 状态 | FIXED |

**关联文档**：`openspec/changes/archive/2026-07-04-cross-model-outside-voice/design.md`

**现象**：sdflow-done 归档+merge 完成后重跑 gate：change 目录已在 openspec/changes/archive/2026-07-04-*/，gate 按 active 路径找 spec-review-report.md 找不到 → REFUSE_START；正确语义应为检测 archive 目录存在 + merge 已发生 → SHIPPED

**根因**：gate 只按 active 路径（`openspec/changes/<change>/`）找 spec-review-report.md；change 归档后目录移入 `archive/`，active 缺席即落 REFUSE_START，缺归档终态识别分支。

**修复方案**（ship-gate-hardening design D3 + 硬化 H1-H6）：
- `decide()` 加 D3 短路（git-sanity 后、pre-flight 前）：纯 git 域发现归档目录（`git ls-tree HEAD∪base` + `re.escape` fullmatch）+ 追读 archived `verify=PASS` tri-state（空壳/冲突→UNKNOWN）+ `base_ref`(refs/heads/) 判是否已并 base → SHIPPED；active 存在时优先 pre-flight（active-wins）。锚测 `test_gate_terminal.py` ×12。

**影响范围**：仅归档后 gate 重跑语义。**已知不覆盖**：evil-merge、精确同名旧档、伪造 subject（已声明接受项）。
