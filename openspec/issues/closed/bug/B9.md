## B9: 200KB 截断按字节切断多字节 UTF-8 字符 → codex 拒收整个 prompt → 该次 voice efficacy=0
> 200KB 截断按字节切断多字节 UTF-8 字符 → codex 拒收整个 prompt → 该次 voice efficacy=0

**关联文档**：`openspec/changes/async-outside-voice/design.md`

**现象**：跑 code-voice 时 codex 报 `Failed to read prompt from stdin: input is not valid UTF-8 (invalid byte at offset 107475)`，rc=1 → exec-error → 降级同族 fallback，跨模型第二意见丢失。context 文件本身是合法 UTF-8（已验），stderr 同时有 OV_TRUNCATED=true。

**根因**：`render_prompt()` 按字节截断 200KB 时直接切在多字节 UTF-8 字符中间，产出非法 UTF-8 序列。

**修复方案**：
- `utf8_head_trim()` / `utf8_tail_skip()` 两个回扫函数，截断点退到最近的 UTF-8 字符边界
- 回扫不可用时 fail-loud exit 1（不兜底成按字节切）

**影响范围**：outside-voice.sh 的 `render_prompt()` 截断路径；修复后 260KB 真实中文 context 截断产出严格合法 UTF-8
> 2026-08-03 状态：VERIFIED → FIXED（change fix-mechanical-layer-silent-failures 归档（2026-07-19），utf8_head_trim/utf8_tail_skip 回扫函数 + 260KB 中文实测）
