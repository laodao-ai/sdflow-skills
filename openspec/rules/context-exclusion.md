# AI 上下文排除规范

> **定位声明**：本规范说明哪些目录/文件**被排除在 Claude Code / Codex 的自动上下文之外**，以及排除的理由。排除不等于禁止访问——需要时仍可手动 `Read`。

## 规则

通过 `.claudeignore`（Claude Code）配置，格式同 `.gitignore`。

### 推荐排除目标

| 类型 | 示例 | 理由 |
|---|---|---|
| 归档历史产物 | `openspec/changes/archive/` | 已归档的 change，当前开发不需要 |
| 实现过程 diff 包 | `**/impl-reports/` | 体积大、信息密度低 |
| spike 实验 | `hack/` | 不是产品代码，需要时手动 Read |
| 个人草稿 | `docs/drafts/` | 非正式文档 |
| 构建产物 | `dist/`、`build/` | 生成文件 |
| 依赖 | `node_modules/`、`vendor/` | 第三方代码 |

### 不排除的（确认保留）

| 类型 | 理由 |
|---|---|
| 工作流规则集 | 经常需要引用 |
| 活跃的 spec | 真相源 |
| 进行中的 change | 正在做的工作 |
| ADR | 设计/实现时频繁查阅 |
| 产品文档 | 日常参考 |

## 维护

- 新增大目录（超过 5M 或 100+ 文件）且日常开发不需要时，考虑加入排除列表
- 排除列表变更时同步更新本 rule
