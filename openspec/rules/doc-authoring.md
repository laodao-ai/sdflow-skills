# DOC-1：正文即最终态，演进史进附录

> **适用**：本仓一切设计/决策类文档——`docs/sad/*` · `openspec/changes/*/{proposal,design,tasks}.md` ·
> `openspec/specs/*/spec.md` · `openspec/adr/*` · `openspec/roadmaps/*` · `CLAUDE.md` · 各 skill 的 `SKILL.md` 与 `references/`。
>
> **不适用**：git commit message · 评审报告（`*-review-report.md`，它们**本来就是**过程记录）· `*-log.md` 类 append-only 留痕。

---

## 规则

**文档正文 = 当前决策的最终态。「为什么不是别的样子」= 附录。**

| | 正文 | 附录 |
|---|---|---|
| 写什么 | **是什么 · 怎么做 · MUST / MUST NOT** | **否决的方案 · 否决理由 · 走过的弯路 · 元教训** |
| 读者 | **第一次读它的人**（含未来的模型） | 想知道「这里为什么不这么设计」的人 |
| 引用方向 | 正文 →〔A-n〕**只给编号，不解释** | 附录可以长、可以啰嗦、可以讲故事 |

### 判据（可操作，不是「写简洁点」）

**① 上一版测试**（主判据）：
> **一句话如果只有「读过上一版的人」才需要，它就不属于正文。**

新读者不知道有过「上一版」。对他而言「原来 X，现在改成 Y」只有 Y 是信息，X 是噪声——而且是**会误导他的噪声**（他得先判断 X 是不是当前方案）。

**② 删除测试**（自检）：
> **把正文里所有含「原来 / 旧版 / 曾经 / round-N / 已作废 / 与旧版的差异 / 本节被收缩 / 留碑」的句子全删掉——正文是否依然完整？**
> **依然完整 ⇒ 那些句子本就该在附录。**

**③ 禁令与理由分离**（最常被误解的一条）：

「MUST NOT 做 X」**是当前决策，留正文**；「因为 X 有 7 个罢工分支……」**是否决理由，进附录**。

```
✅ 正文：lint MUST NOT 对 Makefile 做任何语法解析〔A21〕。
         「target 能不能跑」由 verify-lane 真跑一遍，make 自己判。

❌ 正文：lint MUST NOT 解析 Makefile。原方案是按 selector 重定位 target 提取
         recipe 做 digest，但它在 round-4 被否决了，因为 make 语法无界，实现出来
         带 7 个 fail-closed 罢工分支（ifeq / define / 双冒号 / 一行多 target …），
         而每个罢工分支都是一类项目被拒之门外……（↓ 再来 200 字）
```

**禁令要能独立成立。** 正文读者需要知道的是「不许做」和「那该做什么」，**不需要庭审记录**。

### 反模式清单（正文里见到即违规）

| 反模式 | 长什么样 |
|---|---|
| **墓碑** | 「~~旧字段~~ 已删除（见 A23）」写在正文数据结构里 |
| **新旧对照表** | 「❌ 旧版这样 / ✅ 新版这样」——**新读者根本不需要「旧版」这一列** |
| **修订播报** | 「⚠️ 本节在 round-4 被大幅收缩」「本机制经两次收缩」 |
| **自辩** | 「这不是防伪，因为……（500 字）」——理由进附录，正文只留结论 |
| **元教训** | 「这次的教训是……」——**教训是给回头看的人的，进附录** |

## 为什么这条规则值钱（后果，非美学）

**不是「文档不好看」，是「文档会把评审者引到废弃分支里做优化」。**

**实证（`add-sdflow-devenv`，代价最高的一次）**：`docs/sad/07` 的正文塞满了「为什么这样改」的考古层。
**四轮设计评审、18 面镜、150+ findings，没有一条指出「§3 的起手式错了」**——所有镜子都在**那条错误的推导链内部**做优化（争论信号够不够硬、断言拦不拦得住、digest 要不要规范化）。

**因为正文里到处是「我们已经想过这个了」的痕迹，它看起来像一条被审慎推敲过的路。** 考古层给了错误方向一层**虚假的正当性**。

最后点破它的不是任何一面镜子，是操作者的一句「**怎么感觉越改越乱了**」。

> **一句话**：**正文是路标，不是路上的车辙。** 车辙留在附录里，别铺在路面上。

## 落地

- **写的时候**：每写下一句「为什么不……」，立刻问「这句话新读者需要吗」。不需要 → 剪进附录，正文留〔A-n〕。
- **评审时**：`sdflow-spec-review` / `sdflow-code-review` 的**接地镜**跑一次删除测试（判据 ②）。
- **grep 启发**（**只报不拦**——量大了才是病，一两处是正常的）：

  ```bash
  # 在正文（附录之前）里找考古词面
  awk '/^## 附录/{exit} {print FILENAME":"FNR": "$0}' <doc> \
    | grep -E '原来|旧版|曾经|round-[0-9]|已作废|留碑|与旧版|被收缩|本节.*改判'
  ```

  这不是门禁：**它是提醒**（承 `07` §0.0 闸门 0——该由「问」做的事别做成「拦」）。
