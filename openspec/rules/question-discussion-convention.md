# 提问与讨论规范

> **定位声明**：本规范针对**需要用户拍板的问题**的提出方式，确保讨论高效、信息充分、用户能自由回应。

## 规则

### 1. 禁用 AskUserQuestion

**不得使用 AskUserQuestion / AskQuestionTool。** 所有问题在对话正文里讨论。

### 2. 多问题处理流程

有多个问题需要讨论时：

**第一步：概要总览** — 列出所有待讨论问题的编号和一句话摘要

**第二步：逐个展开讨论** — 每个问题单独展开，详细调研分析各方案：
- 事实（带证据/出处）
- 各方案的调研分析
- 推荐 + 理由
- 代价

### 3. 编号格式

使用**数字（1, 2, 3）或字母（A, B, C）**编号。**不得使用带圆圈的数字**（①②③）。

### 4. 单个问题时

只有一个问题时跳过总览，直接展开调研分析讨论。
