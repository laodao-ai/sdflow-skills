# 脚本标点容错规范

> **定位声明**：本规范针对 **py / sh 脚本处理中文文档时的标点容错**。仓内文档存在中英文标点混用（如 `，` 与 `,`、`：` 与 `:`、`（）` 与 `()`），脚本在解析这些文档时必须对此有容错能力。

## 规则

### 1. 创建脚本时

编写解析中文文档的 py / sh 脚本时，**必须**考虑以下标点对的互换可能：

| 中文标点 | 英文标点 | 常出现场景 |
|---|---|---|
| `，` | `,` | 列表分隔、CSV 风格数据 |
| `。` | `.` | 句末 |
| `：` | `:` | 键值对分隔、表头 |
| `；` | `;` | 多项分隔 |
| `（` `）` | `(` `)` | 括号注释 |
| `"` `"` | `"` | 引用 |
| `'` `'` | `'` | 引用 |

处理方式：

- **分隔符场景**（按逗号拆分、按冒号取键值）：正则或 split 时同时匹配中英文变体
  ```python
  # 好：同时匹配中英文逗号
  items = re.split(r'[,，]', line)

  # 坏：只认英文逗号
  items = line.split(',')
  ```

- **正则匹配场景**（搜索、提取）：字符类里包含中英文变体
  ```python
  # 好：匹配中英文括号内容
  re.findall(r'[(\（](.+?)[)\）]', text)
  ```

- **非分隔场景**（标点只是文本内容的一部分、不影响解析逻辑）：不需要特殊处理

### 2. 调用/修改现有脚本时

修改涉及文本解析的 py / sh 脚本时，**检查**现有的 split / regex 是否已覆盖中英文标点变体。未覆盖的补上。

### 3. 输出保持一致

脚本**输出**不需要容错，但应保持内部一致：选定一种标点风格并贯穿。推荐输出用英文标点（机器友好、无编码歧义）。
