# requirements.md 模板（需求综述 — WHAT）

用途：描述项目"应该做什么 / 为谁做"。read-only 查阅型文档，不频繁更新。

使用方法：把本模板内容 Write 到 `openspec/roadmaps/<name>/requirements.md`，然后按项目实际内容替换 `<占位符>`，删除不适用的节，填写 `<!-- 注释 -->` 引导的内容。
