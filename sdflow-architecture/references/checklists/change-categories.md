# R4 预期变化类别表

> 供 `decomposition-rules.md` R4「变化率检验」使用：逐条标注该类别击中候选子系统的个数，击中 ≥2 → 边界疑点（按 R4 三选一处理）。原始 6 类目（蓝本 §5.1 R4）按变化面归为四组，未删减任何类目。

- **需求面**
  - 需求功能方向变化
  - UI 形态变化
- **规模面**
  - 规模与性能变化
- **技术栈面**
  - 外部协议与依赖版本变化
  - 技术选型替换
- **组织面**
  - 合规要求变化

> 逐条对每个候选子系统打勾「是否受该类变化影响」，同一候选被 ≥2 类命中即触发 R4 边界疑点处理序（移动职责 → 归横切 → 显式接受记 ADR）。
