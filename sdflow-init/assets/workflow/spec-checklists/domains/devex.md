# 领域规则集：DX / 开发者体验（通用）

> `extends: base` —— 只列 developer-facing 交付面（CLI 命令/flag/公共 API/SDK/skill 调用契约/配置面/
> 错误信息文案）特有的设计审查规则；通用质量门禁见 [`../spec-quality-base.md`](../spec-quality-base.md)。
> 触发条件见 `trigger-catalog.md` TG-28。**spec-review-only domain**：本领域清单只在设计审
> （spec-checklists）侧登记，代码审（code-checklists）侧无对应文件（TG-27 反向先例）。
>
> **可判表式**：每条给「触发条件 / 必需文本证据 / PASS / FAIL / N/A」四项判据。评审时先看变更是否命中
> 触发条件，命中则在 design/specs（或 README 等随本次变更同批更新的文档）文本中找「必需文本证据」列
> 所指材料；**找不到该材料时判定输出 `UNVERIFIABLE`，MUST NOT 脑补 PASS**。
>
> **收录范围（分类判据）**：一条内容进本清单当且仅当它是「对着 design/specs 文本可判真伪的检查项」；
> 需要跑外部工具、查竞品、或依赖 `~/.gstack/` 一类运行时状态的过程方法论一律不收（那类方法论不产出
> 可在评审时机械核验的文本证据，与本清单的可判表式定位不兼容）。

---

| ID | 规则 | 触发条件 | 必需文本证据 | PASS 判据 | FAIL 判据 | N/A 判据 |
|----|------|---------|-------------|-----------|-----------|----------|
| DX-01 | **TTHW（Time-To-Hello-World）分档** | 新增/重大修改用户第一次上手路径（quickstart / onboarding 文档段、CLI 首次运行体验） | design/README 的 quickstart 或 onboarding 段所列步骤数与命令数，及由此推导出的 TTHW 估算值与推导规则 | 文本给出步骤数/命令数 + 明确「每步耗时假设（秒）」+ 据此算出的 TTHW 估算值，并显式标注「估算」二字；估算值 `<2min` 为 champion 达标，`>10min` 需红旗说明缓解措施 | 给出裸数字（如「TTHW ≈ 3min」）但未附推导规则——拍脑袋精确数 | 本次变更不涉及新的/被修改的用户上手路径 |
| DX-02 | **错误信息三件套** | 新增/修改面向用户的错误提示文案 | 确切错误文案原文 + 触发条件 + problem/cause/fix 三段是否齐全 | 文案原文可引用，且 problem（说清楚出了什么错）/ cause（为什么会这样）/ fix（下一步该做什么）三段均可在文本中找到 | 文案原文可引用，但 problem/cause/fix 三段缺至少一段 | 本次变更未新增/修改任何面向用户的错误文案 |
| DX-03 | **命名可猜性 / 默认值 / 渐进式披露** | 新增 CLI 命令 / flag / 配置键 / 公共 API 名称，或改变既有默认值 | 新增 surface 的名称 + 与相邻既有命名的对照说明 + 默认值取值与理由；若涉及进阶选项，是否默认隐藏的说明 | 新名称与既有命名风格（动宾结构/大小写/连字符习惯）一致且给出对照说明；默认值有明确理由；进阶选项默认隐藏或有理由不隐藏 | 新命名与既有风格冲突且无对照说明，或默认值无理由 | 本次变更未新增/修改任何用户可见命名或默认值 |
| DX-04 | **升级路径** | 废弃 / 变更已有 CLI 命令、flag、配置键、公共 API | 废弃警告文案 + 迁移说明（from/to 对照）+ 混版本行为描述 | 三者（废弃警告、迁移说明、混版本行为）均可在文本中找到确切引用 | 缺失废弃警告、迁移说明、或混版本行为描述中任一项 | 本次变更未废弃/变更任何已有 developer-facing 交付面 |
| DX-05 | **Claude Code Skill DX 清单** | 新增/修改 SKILL.md 的 `description` 或整体交互设计（sdflow skill 形态新作，非蒸馏第三方清单） | `description` 原文 + 触发场景覆盖度说明 + 失败/降级路径的提示文案 | 三者皆命中：**触发精度**——`description` 含明确触发词/场景且与其他 skill 可区分；**自包含性**——skill 不依赖未声明的外部前置状态即可独立工作；**降级路径可读性**——找不到/失败时的提示文案清晰、给出下一步动作 | 三者中至少一项缺失或文本模糊（如 description 触发词与其他已装 skill 撞车、或失败路径只报错不给下一步） | 本次变更不涉及 SKILL.md 新增或修改 |
