# 领域规则集：前端 / UI（通用）

> `extends: base` —— 只列**前端 / 交互**特有的设计审查规则；通用质量门禁见
> [`../spec-quality-base.md`](../spec-quality-base.md)。框架无关（适用于任何有 UI 的产品）。
>
> 读前端完整规则 = `base` + `frontend` 三层并集。

---

| ID | 规则 | 触发条件 | 检查点 |
|----|------|---------|--------|
| FE-01 | **交互边缘场景** | 新增表单 / 提交 / 异步操作 | double-click / 快速重复提交防护；操作中途离开（返回、关闭标签）的处理；慢网络（API 超时 10s 用户看到什么）；并发操作（同一表单两个标签页） |
| FE-02 | **加载 / 空 / 错误态** | 新增数据展示 / 列表 | 加载中、空结果、请求失败三态是否都有 UI 设计，而非只画 happy path |
| FE-03 | **乐观更新与回滚** | 写操作后即时反馈 | 乐观更新失败时的回滚与提示；提交中按钮禁用/loading，防重复触发 |
| FE-04 | **首屏可辨识 + 克制装饰** | 新增/重做落地页/首屏视觉设计 | 首屏在不看 logo 的情况下能否辨认出品牌调性（非通用模板感）；每张卡片/分区是否有存在必要（能删除且不影响信息传达则删）；去掉装饰性元素后界面是否仍显专业/高级（非靠堆砌装饰堆出的"高级感"） |
| FE-05 | **AI-slop 视觉黑名单** | 新增/重做视觉设计 | 是否落入常见"一看就是 AI 生成"的视觉套路：紫色系渐变背景、图标+圆圈+三列卡片布局滥用、全局居中排版、纯装饰性 blob/几何图形、用 emoji 充当设计元素（图标/插画）替代 |

*规则集 v1 · extends base · 项目无关*
